# E-02 · Реестр организационных ограничений

**Ведётся с:** 2026-09-16 · форма — [`decisions/03-constraints-registry.md`](../../decisions/03-constraints-registry.md) v1.0

## Не используем

| Что | Почему | С какого ADR | Условие пересмотра |
|---|---|---|---|
| Cassandra под ленты | Нет в эксплуатации; выигрыш по стоимости хранения (диск против памяти) при 64 ГБ уходит в шум и не окупает квартал на освоение и второй операционный контур | ADR-0001 · 2026-09-16 | Объём лент вырос на порядок — при 640 ГБ разница снова решающая |
| Valkey | Эквивалентен Redis по всем осям; Redis уже эксплуатируется, причины менять нет | ADR-0001 · 2026-09-16 | Изменились лицензионные условия Redis у нашего провайдера |
| Ленты в основной БД PostgreSQL | 17 400 вставок/с пошли бы в базу, которая уже является узким местом чтения постов | ADR-0001 · 2026-09-16 | Материализация отменена или нагрузка на основную БД снята |
| Оставить границу `web` / `posts` как есть | Связность изменений 68 % при здоровых 80 %; разрез частично идёт по техническим слоям; у `users.last_seen` два писателя | ADR-0002 · 2026-09-16 | Доля задач в одной границе поднялась выше 80 % без переноса линии |
| Выделить ленту третьим сервисом, не трогая границу `web`/`posts` (вариант A) | Дешевле на два шага миграции, но хуже по трём осям; разовая экономия против постоянных издержек на каждой задаче | ADR-0002 · 2026-09-16 | Перенос графа подписок оказался невозможен по техническим причинам |
| Вычистка удалённого поста из всех лент | Миллионы правок ради одного удаления; И2 закрывается фильтрацией при чтении | ADR-0001 · 2026-09-16 | Фильтрация при чтении стала дороже вычистки — то есть удалений стало сопоставимо с чтениями |

## Используем

| Что | С какого ADR |
|---|---|
| Управляемый Redis под материализованные ленты, длина 200 идентификаторов | ADR-0001 · 2026-09-16 |
| Три сервиса — `лента` (с графом подписок), `посты`, шлюз с профилями | ADR-0002 · 2026-09-16 |

## Не рассматривали

- **Собирать ленту при чтении и дальше** — вариант отвергнут вне метода, по разбору кейса: документа решения под материализацию в наборе нет (находка 1 прогона). Решение принято, но не по документу, и это записано честно.

Раздел отличает «решили не брать» от «до этого не дошли»: второе не является решением, ссылаться на него как на решение нельзя.
