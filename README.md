# System Design — рабочая памятка

Справочник по проектированию распределённых систем: **процесс** от требований до design review плюс **карточки топиков**, к каждой из которых можно обратиться отдельно.

Построен на плейлисте [ByteByteGo — System Design Fundamentals](https://www.youtube.com/playlist?list=PLCRMIe5FDPsd0gVs500xeOewfySTsmEjf) (103 видео), дополненный примерно наполовину темами, которых в плейлисте нет — в основном это процесс проектирования, корректность распределённых операций, отказоустойчивость и эксплуатация.

## Как устроена карточка

Все карточки построены одинаково, чтобы их можно было читать по диагонали:

**TL;DR** → **Проблема** (что болит без этого) → **Как работает** → **Когда применять / когда нет** → **Альтернативы** (таблица) → **Trade-offs и режимы отказа** → **Что мерить** → **Связано с** → **Источники**.

Маркировка происхождения: 🎬 — тема из плейлиста, ➕ — добавлена сверх него, 🎬➕ — есть видео, но карточка существенно расширена.

## Индекс «проблема → тема»

Вход по симптому, когда название решения ещё неизвестно.

| Симптом | Куда смотреть |
|---|---|
| БД не справляется с чтениями | T-039 кэш · T-030 реплики чтения · T-026 индексы · T-065 CQRS |
| БД не справляется с записями | T-031 шардирование · T-044 очередь перед записью · T-026 LSM-индексы |
| Дубликаты платежей / повторные заказы | T-012 идемпотентность · T-046 гарантии доставки · T-059 уникальные ID |
| Данные разъезжаются между сервисами | T-047 outbox и CDC · T-058 saga · T-054 модели согласованности |
| Пользователь не видит только что сделанную запись | T-030 read-your-writes · T-041 инвалидация кэша · T-054 causal consistency |
| Один сбойный сервис роняет всю систему | T-072 таймауты и ретраи · T-073 circuit breaker и bulkhead · T-074 деградация |
| Ретраи усиливают аварию вместо восстановления | T-072 backoff и jitter · T-049 backpressure · T-021 rate limiting |
| p99 в разы хуже p50 | T-104 tail latency · T-111 GC-паузы · T-108 пулы соединений · T-042 hot key |
| Кэш «протух» и упала БД | T-042 stampede и hot key · T-040 стратегии записи |
| Два пользователя купили один билет | T-029 уровни изоляции · T-057 распределённые блокировки · T-120 кейс бронирования |
| Нужно отдать событие клиенту в реальном времени | T-010 SSE/WebSocket · T-050 webhooks |
| Долгая операция блокирует запрос | T-044 очередь · T-064 event-driven · W2 асинхронный контракт |
| Растёт стоимость инфраструктуры | T-112 unit-экономика · T-067 serverless · T-020 CDN · W10 trade-offs |
| Выкатка требует простоя | T-091 стратегии деплоя · T-036 миграции без простоя · T-074 фича-флаги |
| Инцидент есть, причина не ищется | T-095 трассировка · T-097 алертинг · T-099 отладка в проде |
| Не понятно, какая БД нужна | T-024 выбор хранилища · T-025 паттерны доступа · [`90-cheatsheets.md`](90-cheatsheets.md) |
| Микросервисы стали медленнее монолита | T-062 модульный монолит · T-063 границы контекстов · T-068 service mesh |
| Аналитика мешает боевой нагрузке | T-035 OLTP/OLAP · T-051 data pipeline |
| API ломается у клиентов при выкатке | T-013 версионирование · T-014 контракты и схемы |
| Утечка или лишний доступ | T-083 модели авторизации · T-086 секреты · T-088 threat modeling |
| Систему надо перенести в другой регион | T-077 multi-region · T-078 RPO/RTO · T-023 глобальная маршрутизация |
| Нагрузка выросла в 10 раз, что делать первым | W5 план масштабирования · T-052 вертикально vs горизонтально |

## О источниках

Каждая карточка ссылается на первоисточники: спецификации (RFC), документацию систем, инженерные статьи и книги. Видео плейлиста указываются как источник темы, но не как единственный — короткий формат неизбежно упрощает, и в спорных местах карточка следует спецификации или первичной публикации, а не пересказу.

Опорные книги и наборы материалов, на которые чаще всего идут ссылки: Martin Kleppmann «Designing Data-Intensive Applications»; Michael Nygard «Release It!»; Google SRE Book и SRE Workbook; AWS Well-Architected Framework и AWS Builders' Library; Sam Newman «Building Microservices»; Alex Xu «System Design Interview» vol. 1–2. Полный список — в [`95-sources.md`](95-sources.md).
